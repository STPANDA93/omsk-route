# Омск, шаг за шагом

[Открыть карту](https://stpanda93.github.io/omsk-route/)

Пять остановок в Омске: G-Drive Арена → Успенский собор → Омская крепость → обновлённая набережная у крепости → фонтан в сквере Дзержинского.

- Пеший маршрут: около 9,2 км, 2 ч 2 мин без остановок.
- Велосипедный маршрут: около 10 км, 46 мин без остановок.
- Нажатие на метку или место в списке открывает фотографию и краткое описание.
- Кнопка «Поделиться маршрутом» позволяет скачать QR-код на сайт.
- Кнопка «Открыть маршрут в Яндекс Картах» передаёт все пять точек и выбранный способ передвижения.

## Карта и данные

Статический сайт без сборки: HTML, CSS и JavaScript. По умолчанию используются Leaflet и OpenStreetMap. Оба пути рассчитаны отдельно сервисом FOSSGIS по сети OSM и сохранены в JSON. Времена ориентировочные, данные проверены 10 ноября 2026 года; ограничения на месте могут измениться.

Для встроенной карты Яндекса нужен собственный доменно-ограниченный браузерный ключ JavaScript API 2.1 в `config.js`. Этот дополнительный режим требует отдельной проверки с действующим ключом. Не размещайте серверные секреты в этом файле.

У каждого фото указан источник. Три фотографии взяты из публикаций 2026 года; даты съёмки арены и крепости не подтверждены. Дата публикации не равна дате съёмки, автоматического обновления фотографий нет. Авторство и ссылки: [assets/README.md](assets/README.md).

## Изменения

Список мест, координаты и описания находятся в `app.js`; фотографии и клиентские библиотеки — в `assets/`. GitHub Pages публикует корень ветки `main`.
